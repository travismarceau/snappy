Snappy 1.2.2

Window placement for macOS

New

  • Drag to place on any display. The placement grid now opens on every connected display at once. Draw a region on whichever screen you want the window on and it moves there — across displays as well as within one. Previously the grid appeared only on the display holding the window, so a drag could never move a window to another screen. Keyboard placements are unchanged: they still act on the display the window is already on.

Fixed

  • Memory that was never released. Each time the placement grid had to be built afresh, the previous one was kept in memory rather than freed, so Snappy’s footprint grew slowly for as long as it stayed running. It is now released as intended. If Snappy has been running for a long time, this update restarts it and reclaims that memory.

Notes

  • No change to permissions or your settings.
