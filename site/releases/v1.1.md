# Snappy 1.1

## ⚠️ You must re-grant Accessibility after this update

Snappy's application identity changed in this release. macOS ties the
Accessibility permission to that identity and to the app's code signature, and
provides no way to carry a grant from the old identity to the new one — so the
permission you granted before does not apply to this build.

**Until you re-grant it, Snappy will start normally and then do nothing.** The
leader key opens no grid and no window moves. There is no error, because as far
as Snappy can tell it simply has not been allowed to move windows yet.

To fix it, after updating:

1. Open **System Settings ▸ Privacy & Security ▸ Accessibility**.
2. If an older Snappy entry is listed, select it and remove it with **−**. A
   stale entry will not grant the new build anything.
3. Add the new Snappy with **+** if it is not listed, then make sure its switch
   is on.
4. Quit Snappy and open it again.

Your settings are not affected. Placements, layouts, snap areas and keyboard
shortcuts are carried across automatically the first time this version runs.
Accessibility is the one thing that cannot be.

## New

- **Automatic updates.** Snappy now checks `getsnappy.fyi` for new versions and
  can install them itself. Every update is EdDSA-signed and the signature is
  verified before anything is applied. This is the last release you have to
  download by hand.
- **Place a window by dragging on the grid.** Bring up the placement grid, drag
  across the cells you want and release — the window lands exactly where you
  drew, whether or not that region was ever saved. Turn it off under
  **Settings ▸ Placements ▸ Drag to place** if you would rather the grid never
  consume a click.
