# Snappy 1.2

## New

- **Report an Issue.** The Snappy menu now has a "Report an Issue…" item. It
  collects the handful of facts that actually determine whether window placement
  can work — whether macOS trusts Snappy, whether Input Monitoring is granted,
  whether Secure Input is currently blocking every application from seeing the
  keyboard, and whether the keyboard hook is really receiving events — and opens
  a prefilled issue with them. Hold Option to copy the report without opening a
  browser.

  These are exactly the conditions that produce "Snappy opens but nothing
  happens", and none of them are visible from the outside. Having them in the
  first message saves a long exchange.

  The report covers Snappy, its permissions and its own settings. It does not
  include window titles, the applications you are running, or any file path
  beyond Snappy itself.

## Fixed

- The download link at `getsnappy.fyi/Snappy.zip` works again. It had been
  serving the website instead of a download since the site moved.

## Notes

Nothing about placement, permissions or your settings changes in this release.
If 1.1 is working for you, 1.2 changes only what happens when it isn't.
